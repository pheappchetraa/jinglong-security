# Vanilla + Tailwind

This is a minimal vanilla JavaScript + Tailwind CSS site, served and bundled with Vite.

- `index.html` — page markup
- `src/main.js` — theme toggle, hero slider, and contact form behavior
- `src/style.css` — Tailwind entry point and theme customization

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run preview` — preview the production build
- `npm run lint` — run Oxlint
